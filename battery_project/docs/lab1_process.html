2. Хронология (10 этапов)

Этап 1.Подготовка

Скачивание/размещение данных NASA PCoE Battery Dataset, установка пакетов, создание структуры проекта.

Входы: NASA PCoE Battery Dataset (.mat, 34 файла)

Выходы: data/raw/*.mat (34 файла)

Файлы: data/raw/B0005.mat data/raw/B0006.mat data/raw/B0045.mat

Ссылки: https://phm-datasets.s3.amazonaws.com/NASA/5.+Battery+Data+Set.zip

Длительность:1 день

Этап 2.Парсинг

Извлечение разрядных (discharge) циклов из .mat в единую таблицу; агрегация статистик по циклу.

Входы: data/raw/*.mat

Выходы: data/processed/raw_cycles.parquet

Файлы: src/parser.py src/config.py

Длительность:1 день

Этап 3.Чистка

Отбраковка физически невозможных измерений, удаление выбросов импеданса по MAD, отметка низкой ёмкости.

Входы: data/processed/raw_cycles.parquet

Выходы: data/processed/clean_cycles.parquet

Файлы: src/clean.py src/config.py

Длительность:1 день

Этап 4.Построение признаков

Лаговые признаки (shift +k), разности, нормировки (capacity_ratio, RUL_frac), скользящие характеристики.

Входы: data/processed/clean_cycles.parquet

Выходы: data/processed/battery_features.parquet

Файлы: src/features.py src/config.py

Формулы: voltage_mean capacity_ratio voltage_diff capacity_slope discharge_rate

Длительность:2 дня

Этап 5.Постановка задач

Три задачи регрессии: RUL_frac (8 батарей), напряжение следующего цикла (34), ёмкость следующего цикла (33).

Входы: data/processed/battery_features.parquet

Выходы: data/processed/battery_rul.parquet data/processed/battery_voltage.parquet data/processed/battery_capacity.parquet

Файлы: src/rul.py src/config.py

Формулы: rul_frac voltage_mean_next capacity_next

Длительность:1 день

Этап 6.Разделение данных

GroupShuffleSplit по батареям (test_size=0.25, random_state=42): батарея целиком в одной части, складок нет.

Входы: parquet-датасеты задач

Выходы: train/val/test 4-2-2 батареи (RUL), 18-7-9 (voltage), 18-6-9 (capacity)

Файлы: src/split.py src/config.py

Длительность:1 день

Этап 7.Обучение MLP

Обучение трёх MLP Dense(64)->Dropout(0.2)->Dense(32)->Dense(1): MSE+MAE, Adam(1e-3), batch=32, early stopping.

Входы: train/val датасеты imputer/scaler (fit на train)

Выходы: model_rul.keras model_voltage.keras model_capacity.keras metrics_*.json

Файлы: src/model.py src/main.py

Длительность:2 дня

Этап 8.Оценка и проверка утечек

Расчёт MAE/RMSE/R² на test, per-battery MAE; проверка отсутствия утечек (scripts/check_leakage.py).

Входы: metrics_*.json сплиты

Выходы: summary_metrics.json отчёт scripts/check_leakage.py → PASSED

Файлы: scripts/check_leakage.py

Длительность:1 день

Этап 10.Сравнение с базовыми предсказателями

Константа (среднее train), линейная регрессия и Random Forest на том же сплите по батареям: нижняя граница качества MLP. График сравнения строится из уже посчитанных метрик.

Входы: parquet-датасеты задач сплиты батарей из metrics_*.json

Выходы: metrics_baselines_{rul,voltage,capacity}.json summary_baselines.json comparison_baselines.json reports/figures/baseline_comparison.png

Файлы: src/baselines.py scripts/run_baselines.py scripts/run_baseline_chart.py

Этап 11.Отчёт и документация

5. Формулы

ID Название LaTeX Plain Используется

mae MAE \(MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|\) MAE = (1/n) · Σ|yᵢ − ŷᵢ| metric

6. Процессы

parsing — Парсинг .mat

Чтение .mat через scipy.io.loadmat(simplify_cells=True), извлечение зарядных/разрядных циклов, агрегация статистик по discharge-циклу.

Входы: data/raw/*.mat

Выходы: data/processed/raw_cycles.parquet

  1. 1. Открыть .mat, найти поле cycle
  2. 2. Для каждого цикла извлечь type (charge/discharge/impedance)
  3. 3. Для discharge посчитать статистики (mean/min/max/std) по Voltage, Current, Temperature
  4. 4. Собрать единую таблицу: идентификатор батареи, номер цикла, дата, статистики цикла
  5. 5. Сохранить raw_cycles.parquet

Исходники: src/parser.py

cleaning — Чистка

Удаление физически невозможных значений и выбросов; отметка низкой ёмкости (EOL).

  • capacity ∉ [0, 2.6] → NaN
  • voltage < 0 → NaN
  • re, rct ∉ [0, 1] → NaN (MAD-правило k=5)
  • первые 3 цикла (формирование) — SKIP_FORMATION
  • cap < 0.5·cap0 → is_low_capacity=True (EOL)

Исходники: src/clean.py

feature_engineering — Построение признаков

Производные признаки: лаги (shift +k), разности, нормировки, скорость разряда.

Признаки: voltage_mean_lag1/lag2 capacity_lag1/lag2/lag3 voltage_diff capacity_diff capacity_slope discharge_rate capacity_ratio (нормировка на cap0)

Исходники: src/features.py

tasks — Постановка задач

Три регрессионные задачи на основе battery_features.parquet.

Выходы: battery_rul.parquet — цель rul_frac (8 батарей) battery_voltage.parquet — цель voltage_mean_next (34 батареи) battery_capacity.parquet — цель capacity_next (33 батареи)

Исходники: src/rul.py

split — Разделение данных

GroupShuffleSplit по battery_id: батарея принадлежит ровно одной части. Preprocessing (imputer, scaler) обучается только на train.

Гиперпараметр Значение
test_size 0.25
random_state 42
group battery_id

Исходники: src/split.py

training — Обучение MLP

Три независимых MLP для трёх задач; ранняя остановка по val MAE с восстановлением лучших весов.

Гиперпараметр Значение
architecture Dense(64) → Dropout(0.2) → Dense(32) → Dense(1)
loss MSE
metric MAE
optimizer Adam(1e-3)
batch_size 32
epochs ≤ 200
early_stopping patience=10
seed 42

Исходники: src/model.py

evaluation — Оценка

MAE/RMSE/R² на test, per-battery MAE, MAE_cycles для RUL.

Исходники: src/export.py

baselines — Сравнение с базовыми предсказателями

Константа (среднее train), LinearRegression (imputer+scaler fit на train), RandomForest(100, rs=42); оценка MAE/RMSE/R² на тесте, сравнение с MLP.

Исходники: src/baselines.py scripts/run_baselines.py scripts/run_baseline_chart.py
