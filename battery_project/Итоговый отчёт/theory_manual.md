## 1. Постановка задачи

**Регрессия** — предсказание непрерывной величины по набору признаков
(в отличие от классификации, где ответ — категория).

Один пайплайн строит три модели одной архитектуры:

| № | задача | цель | единица | батарей (в датасете) |
|---|---|---|---|---|
| A | RUL_frac | `RUL_frac = RUL_cycles / total_cycles` | доли (0–1) | 8 |
| B | Напряжение | `voltage_mean` следующего цикла | В | 34 |
| C | Ёмкость | `capacity` следующего цикла | Ahr | 33 |

Ключевое допущение лабораторной: **одна и та же архитектура** MLP подходит
для всех трёх задач, различаются только признаки и цель.

## 2. Модель: многослойный персептрон (MLP)

### 2.1. Нейрон и слой

Базовый элемент — **нейрон**: взвешенная сумма входов + функция активации:

```
z = Σⱼ wⱼ·xⱼ + b          # взвешенная сумма (b — смещение)
a = f(z)                  # активация
```

- входной слой — признаки (в лабе **15** для задачи A);
- скрытые слои — нелинейные преобразования (в лабе два: **64** и **32** нейрона);
- выходной слой — ответ модели (в лабе **1** число: значение цели).

Параметры — веса `w` и смещения `b`. Общее число параметров:

```
Input(15) → Dense(64):   15·64 + 64          = 1024
Dense(64) → Dropout:                           0
Dropout   → Dense(32):   64·32 + 32          = 2080
Dense(32) → Dense(1):    32·1 + 1            = 33
                                            ───────
                                             3137 параметров
```

### 2.2. Прямой проход (forward pass)

Сигнал идёт от входа к выходу, каждый слой применяет:

```
h₍₁₎ = f(W₍₁₎·x + b₍₁₎)      # первый скрытый слой
h₍₂₎ = f(W₍₂₎·h₍₁₎ + b₍₂₎)    # второй скрытый слой
ŷ    = W₍₃₎·h₍₂₎ + b₍₃₎      # выход (линейный, без активации)
```

### 2.3. Функции активации

- **ReLU** (в скрытых слоях): `ReLU(z) = max(0, z)` — дёшев, нет проблемы
  «насыщения» градиента, при z < 0 градиент 0 (эффект «мёртвых нейронов» — см. §12).
- **Линейный выход** для регрессии: `f(z) = z`. Сеть может вернуть любое
  вещественное число — это требование задачи регрессии (например, напряжение в вольтах).

MLP — **универсальный аппроксиматор**: при достаточной ширине и глубине
может приблизить любую непрерывную функцию на компактном множестве
(широта функции ограничена её гладкостью и объёмом данных).

## 3. Функции ошибок и метрики

### 3.1. MSE — функция потерь (loss)

```
MSE = (1/n) · Σᵢ (yᵢ − ŷᵢ)²
```

- штрафует большие ошибки квадратично → **чувствительна к выбросам**;
- дифференцируема везде → удобна для градиентного спуска;
- в лабе MSE — функция потерь (`loss="mse"`), по ней считается градиент.

### 3.2. MAE — метрика качества

```
MAE = (1/n) · Σᵢ |yᵢ − ŷᵢ|
```

- линейный штраф → **устойчивее к выбросам**, чем MSE;
- в лабе MAE — метрика, по которой отслеживается обучение (`metrics=["mae"]`).

### 3.3. RMSE

```
RMSE = √MSE = √[(1/n) · Σᵢ (yᵢ − ŷᵢ)²]
```

- «среднее» отклонение в **единицах цели**, но с усиленным весом больших ошибок;
- для RUL_frac часто сравнивают RMSE и MAE: если RMSE заметно больше MAE —
  есть крупные выбросы ошибок.

### 3.4. R² (коэффициент детерминации)

```
R² = 1 − SS_res / SS_tot,   SS_res = Σᵢ (yᵢ − ŷᵢ)²,   SS_tot = Σᵢ (yᵢ − ȳ)²
```

- сколько дисперсии цели объясняет модель относительно «предсказания средним»;
- **R² = 1** — идеал; **R² = 0** — модель не лучше константы-средней;
- **R² < 0** — хуже константы (обычно признак плохого сплита или выбросов).

### 3.5. Почему в лабе loss = MSE, а метрика = MAE

Обучение идёт по MSE (гладкая, простой градиент), а отчёт/сравнение — по
MAE и R² (устойчивы к выбросам, интерпретируемы: «в среднем ошибка X единиц»).

## 4. Обучение: метод обратного распространения ошибки

Обучение — подбор `w, b`, минимизирующих MSE. Ключ — **градиент ошибки по весам**.

### 4.1. Алгоритм (два прохода)

1. **Прямой проход** — вычисляем выход сети `ŷ` и ошибку `E = MSE(y, ŷ)`.
2. **Обратный проход** — распространяем ошибку назад через **цепное правило**:

```
∂E/∂wⱼ = ∂E/∂ŷ · ∂ŷ/∂a · ∂a/∂z · ∂z/∂wⱼ
```

Градиент «слоится» от выходного слоя к входному; производные каждого слоя
перемножаются, поэтому глубокая сеть чувствительна к затуханию/взрыву
градиента (в лабе глубина мала — 3 слоя, проблема не критична).

### 4.2. Дельта-правило

Для одного нейрона обновление веса:

```
Δwⱼ = −α · δ · xⱼ,    wⱼ ← wⱼ + Δwⱼ
```

где `δ` — «локальная ошибка» нейрона (для выходного слоя `δ = ŷ − y`
для MSE, далее δ пересчитывается по слоям). По сути дельта-правило —
применение градиентного спуска к каждому весу сети.

### 4.3. Ключевые термины

- **эпоха** — один проход по всему train-набору;
- **batch** — порция данных, по которой считается градиент (в лабе 32);
- **паттерн/итерация** — шаг обновления весов.

---

## 5. Градиентный спуск и оптимизатор Adam

### 5.1. Градиентный спуск

```
w(t+1) = w(t) − α · ∂E/∂w
```

- `α` — **скорость обучения** (шаг);
- движение «вниз» по поверхности ошибки к минимуму;
- риски: слишком малый α — медленное обучение; слишком большой α — расходимость;
- поверхность MSE невыпукла → есть **локальные минимумы** и «сёдла»; результат
  зависит от начальной инициализации весов (в лабе seed 42 для воспроизводимости).

### 5.2. Adam — практическая реализация градиентного спуска

Adam (Adaptive Moment Estimation) — **градиентный спуск с моментом и адаптивным шагом**:

- ведёт **моменты** `m` (среднее градиентов) и `v` (среднее квадратов градиентов);
- делает шаг `независимо по каждому весу`, масштабируя его по `1/√v` —
  частые обновления уменьшаются, редкие — усиливаются;
- устойчив к выбору α; в лабе `Adam(learning_rate=1e-3)`.

Практический эффект: быстрее сходится, менее чувствителен к масштабу признаков
и форме «оврагов» поверхности ошибки.

## 6. Нормализация входов

Признаки имеют разные масштабы (милливольты, амперы, Ahr, номера циклов).
Без нормализации градиентный спуск «пилит зигзагами» и сходится медленно.

```
xᵢ' = (xᵢ − x̄) / σᵢ
```

Формула — **z-score / StandardScaler**: среднее 0, стандартное отклонение 1.

Критическое правило: **fit только на train**, затем `transform` на val и test.
Если fit на всех данных — информация из валидации/теста «протекает» в обучение
(смещение оценки, см. §8).

В лабе:

```
scaler.fit(X_train)   # μ и σ считаются только по train
X_train = scaler.transform(X_train)
X_val   = scaler.transform(X_val)
X_test  = scaler.transform(X_test)
```

## 7. Регуляризация: Dropout и EarlyStopping

### 7.1. Dropout

При каждом шаге обучения случайно «выключает» долю нейронов:

```
Dropout(0.2)  →  20% нейронов слоя в этом шаге не участвуют
```

- сеть не может «зациклиться» на паре нейронов → менее склонна к переобучению;
- на предсказании (inference) dropout выключен — используется вся сеть.

### 7.2. EarlyStopping

Обучение останавливается, если метрика на **валидации** не улучшается `patience` эпох:

```
EarlyStopping(monitor="val_loss", patience=10, restore_best_weights=True)
```

- защита от переобучения (train учится дальше, val уже не падает);
- `restore_best_weights=True` — возвращает лучшие веса, а не последнюю эпоху.
- В лабе максимум `MLP_EPOCHS = 200`, но практически останавливается раньше.

## 8. Честный сплит: GroupShuffleSplit по батареям

Циклы одной батареи **сильно коррелированы** (последовательный процесс
деградации). Если их случайно перемешать по train/val/test — соседние циклы
той же батареи окажутся в разных выборках, и модель «подсмотрит» ответ
**(data leakage)**: метрики будут завышены.

Решение — **группировать по батарее**: валидация и тест состоят из батарей,
которых не было в обучении.

В лабе для RUL (8 батарей), TEST_SIZE = 0.25:

```
train: B0045, B0046, B0048, B0053   (4 батареи)
val:   B0005, B0018                 (2 батареи)
test:  B0006, B0047                 (2 батареи)
```

Метрики на тесте — именно на **невиденных** батареях, это честная оценка.
Обратная сторона: при 2 тестовых батареях оценка сильно зависит от того,
какие батареи попали в тест (маленькая выборка — ограничение лабы).

## 9. Задача A: RUL и нормированная цель RUL_frac

### 9.1. Что такое RUL

`RUL` (Remaining Useful Life) — остаточный ресурс в циклах:

```
RUL_cycles = total_cycles − номер цикла
```

где `total_cycles` — длина серии батареи. Предел ресурса (EOL) в датасете —
падение ёмкости до **0.7 · cap0** (70% начальной ёмкости).

### 9.2. Почему цель — RUL_frac, а не RUL_cycles

При обучении на абсолютных циклах модель для длинной батареи (B0006, 167
циклов) экстраполирует далеко за обучающий диапазон и «заваливается» в
почти константу — MAE сотни циклов. **Нормировка убирает экстраполяцию**:

```
RUL_frac = RUL_cycles / total_cycles   ∈ [0, 1]
```

Все батареи, независимо от длины, теперь лежат в одних границах 0–1 —
модель учится «форме» деградации, а не абсолютной длине.

### 9.3. Перевод обратно в циклы

`RUL_frac` — доля, но отчёт требует «понятную» метрику в циклах:

```
MAE_cycles ≈ MAE_frac · (средний total_cycles тестовых батарей)
           ≈ 0.1051 · 119.0 ≈ 12.5 циклов
```

`119.0` — средняя длина серий тестовых батарей (B0006 — 167, B0047 — 71).

Это **приближённая интерпретация**, не независимая метрика: в реальной
эксплуатации полная длина серии `total_cycles` заранее неизвестна.

## 10. Результаты и их интерпретация

| задача | MAE | RMSE | R² | комментарий |
|---|---|---|---|---|
| RUL_frac | 0.1051 (доли) | 0.1223 | **0.823** | хорошее качество, RMSE > MAE → есть выбросы |
| Напряжение | 0.1127 (В) | 0.2216 | 0.304 | слабое: напряжение почти стабильно, модель близка к «среднему» |
| Ёмкость | 0.1259 (Ahr) | 0.2392 | **0.807** | хорошее качество, деградация предсказуема |

### 10.1. Почему у напряжения низкий R²

Напряжение следующего цикла почти **постоянно** (2–4 В), дисперсия мала,
а разброс ошибки сопоставим с разбросом цели. R² сравнивает ошибку модели с
дисперсией цели: `SS_tot` маленький → даже хорошая абсолютная ошибка даёт
невысокий R². MAE = 0.11 В на фоне ~3 В — абсолютно неплохо, но «выигрыша»
над константой-средней немного.

### 10.2. Аномалии в данных (важно для защиты)

- **B0033, B0034, B0036, B0039, B0041** — резкие падения ёмкости
  (`capacity_ratio < 0.5`), реальные аномалии, не ошибки пайплайна;
- **B0042–B0044** — короткие серии с немедленным падением (быстрый EOL);
- **B0052** — в задаче C исключён честным `dropna` (нет валидного признака);
- **censored-батареи (B0007, B0025–B0028, B0029–B0032, B0038)** — не достигли
  порога 0.7·cap0 к концу записи → **RUL не определён**, они исключены из задачи A.

### 10.3. Per-battery MAE (кто портит метрики)

- напряжение: **B0050 — MAE ≈ 1.032 В** (главный выброс);
- ёмкость: **B0042 — 0.305 Ahr**;
- RUL_frac: B0006 — 0.120, B0047 — 0.070.

## 12. Шпаргалка: вопросы к защите и короткие ответы

1. **Что такое регрессия?** — предсказание непрерывной величины; в лабе три
   непрерывные цели (доля, В, Ahr) одной сетью.

2. **Почему ReLU, а не другие активации?** — дёшев, нет насыщения градиента
   при z > 0; минус — «мёртвые» нейроны при z < 0 (градиент 0), для малых
   сетей некритично.

3. **Почему выход линейный?** — регрессия требует любое вещественное число,
   сигмоид/тангенс ограничили бы ответ интервалом.

4. **Почему loss = MSE, а метрика MAE?** — MSE гладкая для градиента,
   MAE устойчива к выбросам и понятна в единицах цели.

5. **Что показывает R² = 0.823 для RUL?** — модель объясняет ~82% дисперсии
   остаточного ресурса относительно «предсказания средним».

6. **Зачем нормализация?** — признаки в разных масштабах; z-score выравнивает
   их, градиентный спуск сходится быстрее и стабильнее.

7. **Почему StandardScaler fit только на train?** — иначе статистики теста
   «протекут» в обучение и оценка будет смещённой.

8. **Что делает Dropout?** — случайно выключает 20% нейронов на шаге обучения,
   сеть не переобучается на конкретные нейроны.

9. **Что делает EarlyStopping?** — останавливает обучение, когда val_loss не
   снижается patience=10 эпох, возвращает лучшие веса.

10. **Почему сплит по батареям, а не по строкам?** — циклы одной батареи
    зависимы; иначе тест «подсмотрит» соседние циклы из train (leakage).

11. **Что такое Adam?** — градиентный спуск с моментом и адаптивным шагом
    по каждому весу; устойчив к выбору скорости обучения.

12. **Почему RUL_frac, а не RUL_cycles?** — нормировка к [0,1] убирает
    экстраполяцию для длинных батарей, модель учит форму деградации.

13. **Как перевести ошибку в циклы?** — MAE_frac × средний total_cycles теста
    ≈ 0.1051 × 119.0 ≈ 12.5 циклов (приближённая интерпретация).

14. **Почему R² напряжения низкий?** — цель почти константа (малая дисперсия);
    R² сравнивает ошибку с дисперсией, а не с абсолютным уровнем.

15. **Сколько параметров у сети?** — 3137: 1024 + 2080 + 33.

16. **Что за аномалии B0033/…?** — резкие падения ёмкости (< 0.5·cap0),
    реальные дефекты данных, модель их не «лечит», но честно показывает.

17. **Почему RUL только на 8 батареях?** — censored не достигли EOL
    (0.7·cap0), аномальные падают сразу, короткие слишком малы.

18. **Что значит mae_cycles ≈ 12.5?** — это не отдельная обученная метрика,
    а пересчёт долевой ошибки через среднюю длину тестовых серий.

## 13. Глоссарий

| термин | значение |
|---|---|
| MLP | многослойный персептрон, сеть прямого распространения |
| Forward pass | прямой проход: вход → выход |
| Backprop | обратное распространение ошибки, вычисление градиентов по цепному правилу |
| Эпоха | полный проход по train |
| Batch | порция данных для одного обновления весов (32) |
| Learning rate α | шаг градиентного спуска (Adam: 1e-3) |
| StandardScaler | z-score нормализация: (x − μ)/σ |
| Dropout | регуляризация: случайное выключение нейронов (0.2) |
| EarlyStopping | остановка по val-loss с patience и возвратом лучших весов |
| MSE / MAE / RMSE / R² | средняя квадратичная / средняя абсолютная / корневая ошибки / коэффициент детерминации |
| RUL / RUL_frac | остаточный ресурс в циклах / нормированная доля 0–1 |
| EOL | конец ресурса: ёмкость = 0.7·cap0 |
| cap0 | начальная ёмкость батареи (медиана циклов 3–8) |
| total_cycles | длина серии батареи (число разрядных циклов) |
