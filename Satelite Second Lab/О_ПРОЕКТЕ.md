# О проекте — Лабораторная №2: ADAPT, «норма / отказ»

Короткая карта проекта: что считается, что лежит в папках, как запустить и что важно
помнить. Подробности — в `README.md`, числа — в `reports/*.json`.

## Теоретически: что и зачем

**Задача.** Бинарная классификация состояния спутниковой системы по окну телеметрии
ADAPT: `fault = 0` — норма, `fault = 1` — отказ. Окно — 20 последовательных шагов по
81 сенсору, то есть 1620 признаков (`features`) на объект.

**Данные.** 16 экспериментов (записей), 266 окон. Train — 12 экспериментов / 204 окна,
test — 4 эксперимента / 62 окна. Сплит **по экспериментам**: окна одной записи не
попадают одновременно в train и test, иначе соседние окна почти дублируют друг друга
и метрика завышается.

**Модель.** Полносвязная сеть `вход → 128 → 64 → 32 → 1` с `dropout 0.3`,
`LayerNorm` и L2 = 1e-4, 218 305 параметров. Порог решения 0.3952 подобран **только по
валидации** (максимум F1), test в подборе не участвовал.

**Честная оценка.** Кроме hold-out, сделана `LOEO` (leave-one-experiment-out): по
очереди исключается каждый из 16 экспериментов, порог подбирается внутри обучающей
части. Это измеряет разброс, а не выбирает модель.

### Результаты на test (62 окна, 4 эксперимента)

| Модель | accuracy | precision | recall | F1 |
|---|---:|---:|---:|---:|
| Итоговая сеть (порог 0.395) | 0.9032 | 1.0000 | 0.8125 | **0.8966** |
| Сеть до улучшений (0.5) | 0.8065 | 1.0000 | 0.6250 | 0.7692 |
| Логистическая регрессия | 0.726 | 1.000 | 0.469 | 0.638 |
| Постоянный ответ «отказ» | 0.516 | 0.516 | 1.000 | 0.681 |
| Постоянный ответ «норма» | 0.484 | 0.000 | 0.000 | 0.000 |

Ложных тревог — 0, пропущенных отказов — 6 (было 12). `LOEO`: F1 = 0.752 ± 0.329 при
пороге 0.5 и 0.642 ± 0.406 при подобранном пороге — то есть 0.897 на четырёх
экспериментах это верхняя граница, а не типичный результат.

**Главный вывод.** Модель уверенно отделяет отказы (precision 1.0), но нестабильна
между записями: на части экспериментов F1 падает до нуля. Ценность работы — не число
0.897, а измеренный разброс.

## Как запустить

```powershell
.venv\Scripts\python.exe scripts\run_all.py          # полный цикл
.venv\Scripts\python.exe -m src.main_adapt           # обучение и оценка
.venv\Scripts\python.exe scripts\rebuild_report.py   # пересборка отчёта без обучения
.venv\Scripts\python.exe -m pytest tests -q          # тесты
```

## Что важно знать

- Тест — всего 4 эксперимента и 62 окна: один «неудачный» эксперимент двигает F1 на
  десятки процентов. Разброс по фолдам LOEO — от 0 до 1.
- Порог 0.3952 хрупок: он подобран на валидации из немногих окон и не гарантирован
  для другой партии телеметрии.
- `data/interim/`, `data/processed/`, `backups/`, `*.keras` и архивы в git не попадают —
  см. `.gitignore`. Папка не является git-репозиторием, файл подготовлен на будущее.
- `README.md` местами отстаёт от кода (например, список модулей и число рисунков);
  источник истины — файлы в `src/`, `reports/*.json` и `reports/figures/`.
